# Tic Tac Toe

## Overview
Tic Tac Toe is a classic game played on a 3x3 grid. The game is played by two players who take turns marking a cell in the grid with their respective symbols: one player uses 'X' and the other uses 'O'. The goal is to be the first to get three of your symbols in a row, either horizontally, vertically, or diagonally.

## Features
- Simple and intuitive gameplay
- Suitable for all ages
- Can be played by two players
- Easily extendable for additional features

## Game Rules
1. The game is played on a 3x3 grid.
2. Players take turns placing their symbols (X or O) in an empty cell.
3. The first player to get three of their symbols in a row wins the game.
4. If all nine cells are filled and no player has three in a row, the game is a draw.

## Example Gameplay
- Player 1 (X) starts by marking the center cell.
- Player 2 (O) marks one corner.
- Player 1 marks another cell, aiming for a line.
- The game continues until one player achieves three in a row or all cells are filled.
